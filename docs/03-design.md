# Как устроено и как пользоваться

## Схема

```
  я (телефон, ноутбук)                    проекты: cvs, tinder, …
          │ WebRTC, через VPN                     │ require('meatsuit')
          ▼                                       ▼
 ┌──────────────── сервер, Docker ──────────────────────────────┐
 │  Neko: Brave с постоянным профилем  ◄── CDP (только внутри) ──┤
 │        /data/profile                    meatsuit-клиент:      │
 │                                         очередь, руки, лимиты │
 └──────────────────────────┬────────────────────────────────────┘
                            │ выход в интернет
                            ▼
                    домашний IP (см. «Открытые вопросы»)
```

**Браузер один.** Neko показывает его мне, а через порт CDP к нему подключаются боты. Порт открыт только внутри Docker-сети, наружу не торчит.

## Части

| Часть | Что делает |
|---|---|
| `docker/` | образ Neko с Brave, том с профилем, CDP во внутреннюю сеть |
| `index.js` | `connect()`: подключение к браузеру через Patchright `connectOverCDP`, получение вкладки, навешивание рук |
| `human.js` | мышь, клик, прокрутка, ввод (уже есть) |
| `queue.js` | один бот за раз, ритм и лимиты по площадкам |
| `guard.js` | распознаёт капчу, страницу входа и «подозрительную активность», после этого стоп и сообщение в телегу |

## Как пользоваться

### Мне

- Открываю `https://browser.<сервер>` (только через VPN) и живу в браузере как обычно.
- Нужен новый вход: вхожу там руками, больше ничего делать не надо.
- Бот застрял на капче: приходит сообщение в телегу, я открываю зеркало и решаю капчу сам.

### Проекту

```js
const meatsuit = require('meatsuit');

await meatsuit.task('cvs:hh-apply', async (page) => {
  await page.goto(vacancyUrl);
  await page.human.click('Откликнуться');
  await page.human.fill('Сопроводительное письмо', letter);
  await page.human.click('Отправить');
}, { site: 'hh.kz' });
```

Что делает `task()`:
1. Встаёт в очередь. Пока выполняется чужая задача, ждёт.
2. Проверяет лимит площадки на сегодня. Если лимит исчерпан, бросает `LimitReached` и в браузер не заходит.
3. Открывает **отдельное окно**, мои вкладки не трогает, и закрывает его в конце.
4. После каждого перехода проверяет страницу через `guard`. Капча или страница входа — бросает `NeedsHuman`, проект откладывает задачу.
5. Пишет в журнал, кто, где, когда и чем закончил.

Ритм и лимиты задаются в `sites.json`, а не в коде проекта:

```json
{ "hh.kz":        { "perDay": 15, "perHour": 3, "hours": "10-21" },
  "linkedin.com": { "perDay": 0 },
  "greenhouse.io":{ "perDay": 25, "perHour": 4, "hours": "9-22" } }
```

`perDay: 0` значит, что бот на этой площадке ничего не делает. LinkedIn пока стоит так: там риск выше, а терять сеть контактов нельзя.

### Руки: что умеет `page.human`

| Вызов | Как ведёт себя |
|---|---|
| `click(что)` | ищет по тексту кнопки, ссылки или подписи (или принимает locator), прокручивает к элементу, ведёт мышь по кривой в одном из трёх темпов (см. ниже), кликает в случайную точку. Курсор уже над элементом — мышь не двигается |
| `fill(поле, текст)` | клик в поле по подписи, потом ввод |
| `type(текст)` | по символу, скорость плавает, изредка опечатка и Backspace |
| `scroll(px?)` | колесом рывками, иногда остановка «прочитать» |
| `pause(от, до)` | случайная пауза |

#### Темпы мыши

Темп выбирается случайно на каждое движение (`fast` 35%, `normal` 45%, `slow` 20%) или задаётся вызовом (`click(page, loc, { speed })`). План движения — чистая функция `plan(from, to, { speed })` в `human.js`, её проверяет `test/human.test.js`.

| Темп | Длительность на длинной дистанции | Перелёт мимо цели | Пауза перед нажатием |
|---|---|---|---|
| `fast` («аим») | 0,6–1,3 с | в 65% случаев | 30–140 мс |
| `normal` | 1,0–1,9 с | в 15% | 80–350 мс |
| `slow` | 1,8–3,2 с | в 5% | 150–600 мс |

- Короткие переходы пропорционально быстрее длинных.
- **Перелёт.** Мышь доходит до точки на 10–45 px за целью (и чуть в сторону), на мгновение замирает («заметил промах»), потом возвращается 3–6 короткими дёргаными шажками, дрожь затухает к цели. Последняя точка плана всегда ровно цель, клик попадает в элемент.
- **Курсор уже на кнопке.** Если после прошлого движения курсор лежит внутри элемента (не у самого края), мышь не трогаем; в 15% случаев всё равно слегка смещаемся, чтобы поведение не было механическим.
- Курсор запоминается на странице. В новом окне первое движение стартует из случайной точки.

Дальше: закон Фиттса для длительности, как у ghost-cursor (сейчас длительность зависит от дистанции грубее). Позже, может быть, поиск кнопки моделью, когда текст не нашёлся, как в Stagehand.

## Решения

| Решение | Почему |
|---|---|
| Один браузер для всех, а не по профилю на проект | живой человек — лучший прогрев. Площадки и так знают, что это один я |
| Neko, а не noVNC | WebRTC: видео со звуком, кино смотреть можно |
| Patchright `connectOverCDP` | API Playwright без служебных команд DevTools |
| Отдельное окно на задачу | бот не трогает мои вкладки, и я вижу, что он делает |
| Капча означает стоп, а не обход | обход — гонка вооружений и прямой путь к бану |
| Без подмены отпечатков | настоящий браузер согласован сам с собой |

## Открытые вопросы

1. **IP.** С сервера в интернет идёт IP датацентра, а это главный признак бота после протокола. Варианты: туннель WireGuard до домашнего роутера (бесплатно, но зависит от дома и скорости), резидентный прокси (платно, IP чужой), оставить браузер на домашнем компе (тогда сервер не нужен). Решаем до переезда.
2. **Я и бот одновременно.** Brave один, мышь в нём одна. Если я смотрю кино, а бот кликает в своём окне, Neko покажет активное окно. Что увижу я, и не притормозит ли браузер фоновую вкладку бота? Проверяется первым же прототипом.
3. **Patchright через `connectOverCDP`.** Его заплатки остаются в силе при подключении к уже запущенному браузеру, или только при своём запуске? Проверить на сайтах-детекторах.
4. **Brave в Neko.** Готового образа может не быть, тогда нужно взять Chromium или собрать свой.
5. **Перенос входов.** Профиль ноутбука `~/.apply-profile` переносить или войти заново через зеркало? Скорее заново: новое устройство и так новое.
