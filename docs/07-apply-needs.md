# Задание: доработки meatsuit для автоотклика (cvs)

Контекст: `../cvs` учится сам откликаться на вакансии через meatsuit: на hh и в формах работодателей (Greenhouse, Lever, Ashby, Workable, сайты компаний). План и решения лежат в `../cvs/docs/superpowers/plans/2026-10-07-auto-apply-hh.md`. Бот cvs пишется по контракту `docs/04-contract.md` и в код meatsuit не лезет. Без пунктов 1–3 формы работодателей уходят человеку (`manual`).

Правила работы те же, что в `06-tinder-fixes.md`: самое маленькое правильное изменение; каждое изменение поведения сопровождается тестом и правкой `docs/04-contract.md`; существующие тесты не ослаблять. Если в рабочем дереве лежат чужие незакоммиченные правки, их не сбрасывать и с этой задачей не смешивать. Порядок относительно `06-tinder-fixes.md` выбирает владелец.

Приоритеты: **1 → 2 → 3** нужны боту, 4 желательно.

---

## 1. Команда `upload`

**Проблема.** Форме работодателя почти всегда нужен PDF резюме, а в закрытом наборе команд загрузки файла нет.

**Что сделать.** `{ cmd: 'upload', id, gen, file }`.
- `file` — абсолютный путь. Разрешены только файлы внутри `uploadDirs` из опций `task` (без них команда — `BadCommand`), расширения `pdf`, `doc`, `docx`, размер до 10 МБ.
- Цель `id` — один из двух вариантов: `<input type=file>` или видимая кнопка или метка, которая открывает выбор файла. Для кнопки: обычный человеческий клик, затем `page.waitForEvent('filechooser')` и `setFiles`. Для input: `setInputFiles`.
- Файл передавать буфером (`{ name, mimeType, buffer }`), а не путём: на сервере браузер живёт в контейнере neko, и пути с хоста там нет.
- `eyes`: показывать `<input type=file>` в `elements`, даже если он визуально скрыт, но видна его метка или кнопка. Поле `inputType: 'file'`, `name` из label, aria или соседней кнопки. Без этого бот не видит, куда загружать.
- dryRun: команда не выполняется, только пишется в журнал.

**Готово, когда:** тест на фальшивой странице для обоих вариантов (input и кнопка с filechooser), отказ вне `uploadDirs` и для чужого расширения; контракт описывает команду.

## 2. Правило по умолчанию для неописанных хостов

**Проблема.** Хост формы становится известен только в момент отклика: `job-boards.greenhouse.io`, `jobs.lever.co`, `jobs.ashbyhq.com`, `apply.workable.com`, `<компания>.recruitee.com`, сайты компаний. Перечислить их заранее нельзя, а `limits.check()` на неописанной площадке бросает `LimitReached`.

**Что сделать.** Необязательный ключ `"*"` в `sites.json` — правило для хостов, которых нет в файле. Счётчики при этом ведутся по каждому хосту отдельно, как сейчас по площадке. Явная запись важнее `*`: `linkedin.com` с `perDay: 0` остаётся закрытым. Без `*` всё работает как раньше.

Значения предлагает cvs, утверждает владелец:
```json
"*":     { "perDay": 3,  "perHour": 2, "hours": "9-21",  "maxCommands": 80, "maxMinutes": 12 },
"hh.kz": { "perDay": 5,  "perHour": 2, "hours": "10-20", "maxCommands": 60, "maxMinutes": 10 },
"hh.ru": { "perDay": 5,  "perHour": 2, "hours": "10-20", "maxCommands": 60, "maxMinutes": 10 }
```

**Готово, когда:** тест в `limits`: неописанный хост берёт правило `*`, явная запись перекрывает `*`, без `*` прежний `LimitReached`.

## 3. Невидимая reCAPTCHA — не капча

**Проблема.** `guard.check()` объявляет капчей любой iframe, в адресе которого есть `recaptcha`. На Greenhouse, Lever, Ashby и многих формах висит невидимая reCAPTCHA v3 или Enterprise (`…/recaptcha/api2/anchor?…&size=invisible`, `…/recaptcha/enterprise/anchor?…&size=invisible`), которая ничего не просит у человека. В итоге бот остановился бы на каждой такой форме.

**Что сделать.** Iframe с `size=invisible` в адресе капчей не считается. Видимое задание по-прежнему стоп: открытый `bframe` с картинками, галочка «I'm not a robot», hCaptcha, Cloudflare Turnstile. Сначала проверить в `eyes.js`, какие iframe попадают в `frames`: только видимые или все. От этого зависит, виден ли скрытый `bframe`. Обхода нет: показала reCAPTCHA задание — стоп и сообщение человеку.

**Готово, когда:** тесты `guard`: невидимый якорь проходит, видимый виджет и задание дают `капча`.

## 4. (желательно) Видно, что файл прикрепился

После `upload` в снимке должно быть видно, что файл встал: `value` у input (Chrome отдаёт `C:\fakepath\имя.pdf`) или имя файла в тексте страницы. Тогда бот проверит загрузку и не отправит форму без резюме.
