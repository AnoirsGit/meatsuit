## Сделано: `docs/06-tinder-fixes.md`

Каждый пункт сделан с тестом и правкой `docs/04-contract.md`. Без новых флагов всё ведёт себя как раньше.

- **п.1 `singleTab`** (`index.js`: `siteTab`, `task`; `test/single-tab.test.js`).
  - Задача идёт в открытой вкладке площадки и не закрывает её.
  - Вкладка ищется до `reserve`, поэтому сбой поиска слот не тратит.
  - Любую найденную вкладку проверяет guard (снимок без команд). Если не прошла: `NeedsHuman` и уведомление `needsHuman`, страница не тронута. Защита не зависит от процесса и работает при запусках по cron.
  - Окно, открытое задачей и оставшееся не на площадке, закрывается.
- **п.2 `see({ settle })`** (`hands.js`: `settled`). Ждёт, пока DOM замрёт и элементов хватит. По таймауту отдаёт последний снимок. `timeoutMs` ограничен `MAX_WAIT` (15 с), иначе он обходил бы `maxMinutes`.
- **п.3 `task({ dryRunNavigation })`** (`hands.js`, `human.js`: `verifyAt`).
  - В dryRun выполняется только клик по `role=tab`.
  - Перед `mouse.down` `hitsTarget` проверяет, что в точке клика лежит вкладка. Если между точкой и вкладкой есть интерактивный элемент, клик отклоняется (`StaleElement`). Список интерактивных: `INTERACTIVE`, копия `SELECTOR` из `eyes.js`.
  - Проверка заходит в open shadow.
- **п.4 `task({ readOnly })`** (`limits.js`: `check`, `reserve`, `charge`; `supervise.js`: `isWrite`, `onWrite`).
  - Read-only задача тратит только `perHour`.
  - Перед первой командой записи списывается полный слот дня. Если `perDay` исчерпан, приходит `LimitReached` и команда не выполняется.
- **п.5, бэклог.**
  - Shadow DOM в `eyes.js`: `deepAll`; `covered` спускается в корни; `inside` идёт через `assignedSlot`; `textOf` собирает имя через `<slot>`; из корней берётся только отрисованный текст (Range), иначе `<style>` ломал guard на страницах-заглушках.
  - Гонка `lock` в `limits.js`: брошенный замок забирается под вторым замком `.reclaim`.
- Упоминания других проектов из моих правок в контракте и `hands.js` убраны. Пользователь просил, чтобы они не расползались по meatsuit.

Каждую волну смотрел свежий субагент-ревьюер. Найденное в волнах 1 и 2 исправлено.

## Открыто: начать с этого

1. **Ревью третьей волны пришло, найденное не исправлено.** В `siteTab` проблем нет, `INTERACTIVE` совпадает с `SELECTOR`. Тесты эти находки не ловят:
   - **dryRun выполняет запись** (`hands.js` ~162, средняя). `hitsTarget` смотрит путь от точки клика только до вкладки. `<a href><div role="tab">` или `<button><span role="tab">` в форме: клик проходит, срабатывает ссылка или отправка формы. Починка: от вкладки подняться вверх по составному дереву и отклонять клик, если есть предок из `INTERACTIVE` (или хотя бы `a[href]`, `button`, `label`, `summary`, `input`). Нужен тест.
   - **Регрессия guard** (`eyes.js` ~120, средняя). Текст shadow-корней дописывается в `text`. Shadow-виджет на несколько сотен символов (баннер cookie) поднимает длину выше `BLOCK_PAGE_MAX_TEXT = 600`, и guard не видит заглушку «Too many requests» из light DOM. Починка: применять порог к light-тексту и к тексту каждого корня отдельно. Нужен тест.
   - **Теряется текст прямо в shadow-корне** (`eyes.js` ~121, средне-низкая). Берутся `shadowRoot.children`, а текстовые узлы верхнего уровня, куда рендерит Lit, пропадают: «Please verify you are human» не виден guard. Починка: обходить `childNodes`, для текстовых узлов проверять отрисовку через `range.selectNode(t).getClientRects()`.
   - **Скрытый текст и CSS в имени кнопки со слотом** (`eyes.js` ~98, низкая). Возможен ложный стоп guard. Починка: для детей, у которых `drawn(n)` ложно, брать `''`.

## Бэклог: известные слабости

- `release()` в `lock` не проверяет владельца. Если держатель замер дольше `staleMs` (пауза контейнера), в секции окажутся двое.
- Пока капча висит, каждый запуск cron шлёт `needsHuman` заново. Дедупликации нет.
- У кнопок со `<slot>` `same()` не видит подмену подписи между `see` и `act`: `innerText` у них пуст.
- `INTERACTIVE` в `hands.js` не связан тестом с `SELECTOR` в `eyes.js`.
- Отрисованный текст через Range проверен только на Chromium 153.
- Закрытые (closed) shadow-корни не видны ни `eyes`, ни `guard`.
- Patchright не подключён: работает обычный playwright-core.
