**Главный вывод ресёрча.** Файла `cvs/research/25-not-looking-like-a-bot.md` на диске нет (проверено 05.10.2026), так что вывод держится на одном бенчмарке и проверяется спайком. При 10–40 действиях в день бота выдаёт не объём. Выдают три вещи: протокол управления браузером (служебные команды DevTools), IP датацентра и неживое поведение на формах с reCAPTCHA. Подмена отпечатков без починки протокола почти ничего не даёт ([benchmark](https://ianlpaterson.com/blog/anti-detect-browser-benchmark-patchright-nodriver-curl-cffi/)).

## У других

### Незаметное управление браузером

| | Что это | Берём? |
|---|---|---|
| [Patchright](https://github.com/Kaliiiiiiiiii-Vinyzu/patchright) | Playwright с тем же API, без служебных команд DevTools | **да**, это основа |
| [nodriver](https://github.com/ultrafunkamsterdam/nodriver) | Python, управляет системным Chrome напрямую, в замере 0 блокировок | нет: у нас Node, лицензия AGPL |
| [Camoufox](https://github.com/daijro/camoufox) | Firefox с подменами на уровне C++ | нет: другой движок, профиль Brave не перенести |
| rebrowser-patches | заплатки для Playwright | нет: в замере блокируется так же, как обычный Playwright |

### Человеческая мышь

| | Что это | Берём? |
|---|---|---|
| [ghost-cursor](https://github.com/Xetera/ghost-cursor) | Безье и закон Фиттса: шагов тем больше, чем дальше цель и меньше элемент. Перелёт и доводка, случайная точка внутри элемента | **идею да**: шаги по Фиттсу добавить в `human.js` |

### Удалённый браузер на сервере

| | Что это | Берём? |
|---|---|---|
| [Neko](https://github.com/m1k1o/neko) | браузер в Docker, картинка и звук через WebRTC. Можно смотреть видео, управлять в несколько человек, профиль постоянный, есть подключение Playwright | **да**, это зеркало |

### ИИ поверх браузера

| | Что это | Берём? |
|---|---|---|
| [Stagehand](https://stagehand.dev) | обёртка над Playwright: `act("нажми откликнуться")`, `extract()`, `observe()`, кэширует найденные действия | **идею да**: искать кнопку по описанию, когда текст или селектор не сработал. Не сейчас |
| [Browser Use](https://www.skyvern.com/blog/browser-use-vs-stagehand-which-is-better/) | автономный агент: ставишь цель, он сам решает каждый шаг | нет: каждый шаг идёт через модель, это дорого и непредсказуемо, а клики выходят нечеловеческими |

## Чего ни у кого нет

Готовые решения делятся на две группы: «много одноразовых браузеров для ботов» (Browserless, Steel) и «один удалённый браузер для человека» (Neko). Нет решения, где **человек живёт в браузере сам, а боты работают в том же браузере аккуратно и по очереди**. Эту нишу и занимает meatsuit. Лучший прогрев — это настоящая жизнь в браузере, а не скрипт, который изображает серфинг.
