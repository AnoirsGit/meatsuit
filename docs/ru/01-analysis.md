## У других

### Незаметное управление браузером

| | Что это | Берём? |
|---|---|---|
| [Patchright](https://github.com/Kaliiiiiiiiii-Vinyzu/patchright) | Playwright с тем же API, без служебных команд DevTools | **да**, это основа |
| [nodriver](https://github.com/ultrafunkamsterdam/nodriver) | Python, управляет системным Chrome напрямую, в замере 0 блокировок | нет: у нас Node, лицензия AGPL |

| rebrowser-patches | заплатки для Playwright | нет: в замере блокируется так же, как обычный Playwright |

| | Что это | Берём? |

## Чего ни у кого нет

Готовые решения делятся на две группы: «много одноразовых браузеров для ботов» (Browserless, Steel) и «один удалённый браузер для человека» (Neko). Нет решения, где **человек живёт в браузере сам, а боты работают в том же браузере аккуратно и по очереди**. Эту нишу и занимает meatsuit. Лучший прогрев — это настоящая жизнь в браузере, а не скрипт, который изображает серфинг. Это допущение без источника; автопрогрев (`life.js`) только добавка на дни, когда меня в браузере не было ([06-warmup.md](06-warmup.md)).
