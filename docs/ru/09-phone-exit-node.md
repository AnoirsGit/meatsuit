# Телефон дома как exit node: первая настройка

20.10.2026. Записка для владельца. Телефон A57 (OPPO A57 на ColorOS или Samsung Galaxy A57 на One UI — уточнить по
приходу) лежит дома на зарядке и Wi-Fi и служит exit node Tailscale вместо Pi Zero из [08-pi-zero.md](08-pi-zero.md).
`anoir-pc` остаётся запасным: если телефон пропал, контейнер сам переходит на ПК и возвращается, когда телефон снова в
сети. Как это устроено — [egress.md](../egress.md#fallback-order), здесь только шаги.

**Ничего из этого на телефоне ещё не проверено:** его нет. Названия пунктов меню в ColorOS и One UI меняются от версии к
версии; если пункта нет там, где написано, ищите по словам в поиске настроек.

## 1. Tailscale на телефоне

1. Обновить систему, поставить Tailscale из Google Play, войти тем же аккаунтом, что и остальные машины.
2. В приложении: меню (три точки или «Settings») → **Run as exit node** → включить. Android спросит про VPN — разрешить.
3. В админке <https://login.tailscale.com/admin/machines>, у новой машины в меню «…»:
   - **Edit machine name** → `home-phone` (это имя пойдёт в список на сервере);
   - **Edit route settings** → галочка **Use as exit node**;
   - **Disable key expiry** — иначе через полгода узел выпадет из tailnet.

## 2. Чтобы Android не убил Tailscale

Без этого телефон в первую же ночь «уснёт» вместе с туннелем.

- **Постоянная VPN.** Настройки → поиск «VPN» → Tailscale (шестерёнка) → **Постоянная VPN / Always-on VPN** включить.
  Android сам поднимет Tailscale после перезагрузки или если его убили. «Блокировать соединения без VPN» не нужно.
- **ColorOS (OPPO A57, Android 12):**
  - Настройки → Приложения → Tailscale → **Использование батареи**: «Разрешить фоновую активность» вкл., «Разрешить
    автозапуск» вкл., «Разрешить запуск другими приложениями» вкл.;
  - Настройки → Батарея → «Ещё настройки»: «Оптимизировать использование батареи» / «Умное энергосбережение» —
    выключить для Tailscale (или целиком); режим энергосбережения не включать;
  - в недавних приложениях потянуть карточку Tailscale вниз (или ⋮ → «Заблокировать»), чтобы появился замок.
- **One UI (Samsung):**
  - Настройки → Приложения → Tailscale → Батарея → **Без ограничений**;
  - Обслуживание устройства → Батарея → «Ограничения фонового использования» → «Приложения, которые никогда не
    переходят в спящий режим» → добавить Tailscale; «Переводить неиспользуемые приложения в спящий режим» выключить;
  - в недавних: значок Tailscale → «Не закрывать».
- Phantom process killer Android 12 убивает дочерние процессы приложений вроде Termux; Tailscale он не касается. Для
  remora (пересылка SMS через Termux) это отдельная история, см. её README.

## 3. Wi-Fi и SIM

Через exit node трафик должен уходить только по домашнему Wi-Fi. Если телефон молча перейдёт на мобильные данные, сайты
увидят адрес оператора, а не дома.

- **Мобильные данные выключить.** SIM при этом принимает SMS и звонки. Это главная защита: сервер проверяет выход
  раз в ~5 минут, и между проверками трафик через оператора был бы не замечен.
- **Переключение на мобильную сеть выключить:** ColorOS — Wi-Fi → ⋮ / «Дополнительно» → «Wi-Fi-ассистент»,
  «Автопереключение на мобильную сеть», «Двухканальное ускорение» — всё выкл.; One UI — Wi-Fi → ⋮ → «Дополнительно» →
  «Переключаться на мобильные данные» выкл.
- **Wi-Fi во сне:** если в «Дополнительно» есть «Wi-Fi в спящем режиме» — «Всегда».
- Держать ближе к роутеру: у Pi Zero главная беда была слабый сигнал.

## 4. Зарядка круглые сутки

Включить защиту батареи: Samsung — Батарея → «Защита аккумулятора» (предел 85 %); OPPO — Батарея → «Оптимизированная
зарядка» / «Умная зарядка». Класть не на мягкое и не под солнце.

## 5. Сервер

Деплой — владелец (или по его «да»). В файле деплоя meatsuit на боксе (`/opt/meatsuit/docker/.env`) добавить три строки,
`TS_EXTRA_ARGS` не трогать (при старте нужен адрес, имя там не принимается):

```sh
MEATSUIT_EXIT_NODES=home-phone,anoir-pc
MEATSUIT_EXIT_COUNTRY=<страна>      # с домашнего Wi-Fi открыть https://ipinfo.io/json: поле country
MEATSUIT_EXIT_ASN=<номер>           # там же: число из поля org после «AS»; несколько — через запятую
```

Затем обновить клон до ветки с `docker/egress/exit-picker.sh` и пересоздать стек: Tailscale и всё, что живёт в его сети
(браузер, прогрев и HTTP-сервис, если включены; профиль в томе не пропадает):

```sh
docker/up.sh up -d --force-recreate
```

После этого пересоздать стеки, которые подключены к браузеру через `container:meatsuit-browser` (сервис `apply` у cvs,
бот tinder-matcher): со старым сетевым окружением они остаются без сети, как в шаге 8 [08-pi-zero.md](08-pi-zero.md).

Если в `profiles/egress.json` (замороженный прогрев и HTTP-сервис) записаны номера провайдеров — там должен быть только
домашний, не мобильный.

## 6. Проверка

1. `docker/up.sh exec tailscale sh /exit-picker.sh status` — у `home-phone` в колонке chosen `yes`, в probe
   `ok <страна> <номер>`, внизу `gate: open`.
2. В зеркале открыть <https://ipinfo.io>: страна и провайдер домашние.
3. Учебная тревога: на телефоне выключить Wi-Fi. Через несколько минут `docker/up.sh logs --tail 20 tailscale` пишет
   `exit-picker: exit node: anoir-pc (…)`, в зеркале ipinfo по-прежнему домашний. Включить Wi-Fi: минуты через две после
   того, как телефон снова в сети, выход вернётся на него.
4. Скорость: шаг 5 «Verify» в [egress.md](../egress.md#verify) — через телефон, потом через ПК; записать обе цифры.
5. Если `gate: closed` и браузер без сети: ни один узел не прошёл проверку. Смотреть `status` (колонка probe) и логи:
   `wrong … AS <номер оператора>` — телефон ушёл на мобильные данные (шаг 3); `unknown` — дом без интернета или
   ipinfo/ipwho.is недоступны.
