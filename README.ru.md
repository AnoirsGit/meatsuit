# meatsuit

**meatsuit — это просто запуск браузера, запоминание и потом глаза и руки. Все учётные данные (креденшелы) выдаёт тот, кто обращается.**

[English](README.md) · [Документация](docs/README.md) · [Что дальше](docs/ROADMAP.md) · [Как участвовать](CONTRIBUTING.md)

Больше ничего. meatsuit запускает один браузер, хранит его профиль, чтобы вход, сделанный один раз, не пропадал, и даёт вашему коду смотреть на страницу (глаза) и действовать в ней как человек (руки). Своих аккаунтов, задач и расписания у него нет: пароли, токены, лимиты и решение, что делать, приносит вызывающий. На деле это две части:

1. **Библиотека для Node** (`connect` / `task` / `see` / `act`). Ваш проект подключается к запущенному браузеру по CDP, берёт его на одну короткую задачу за раз, видит страницу как текст и список элементов с номерами и действует по ним человеческими мышью и клавиатурой. Капча, страница входа или блок останавливают задачу (`NeedsHuman`), окно остаётся человеку.
2. **Зеркало браузера** в Docker ([Neko](https://github.com/m1k1o/neko)): один постоянный браузер — по умолчанию Google Chrome, можно Brave, — который человек открывает с обычной веб-страницы. Профиль живёт в томе: вход на сайты делается руками один раз, и этой сессией пользуются все вызывающие.

Учётные данные всегда приносит вызывающий. Библиотека не читает окружение и сама никуда не шлёт: лимиты площадок (`sitesFile`), каталог состояния (`dir`) и уведомления (`notify`) — аргументы `connect()`. Паролей сайтов, ключей моделей и токенов ботов в meatsuit нет.

```
  ваш проект (Node)                            вы (ноутбук, телефон)
  connect({ cdpUrl, sitesFile, notify })               │ веб-зеркало (WebRTC)
  task(site, ({ see, act }) => …)                      ▼
          │ CDP                      ┌──── Docker: контейнер meatsuit-browser ────┐
          └────────────────────────► │ Neko + Google Chrome (или Brave), CDP 9222  │
                                     │ профиль в томе meatsuit_profile             │
                                     └─────────────────────────────────────────────┘
```

## Быстрый старт

Нужны Node 20+, для зеркала — Docker с Compose 2.24 или новее.

**Зеркало.**

```sh
npm ci
npm run init        # файл деплоя docker/.env: права 0600, случайные пароли зеркала; повторно ничего не трогает
npm run config      # по желанию: временная страница на 127.0.0.1, чтобы посмотреть и поправить файл (печатает одноразовую ссылку)
docker/up.sh        # docker compose --env-file <файл деплоя> up -d
docker/verify.sh    # управляет зеркалом и проверяет по CDP, что браузер действительно это сделал
```

Откройте `http://127.0.0.1:8080`, имя любое, пароль участника — из файла деплоя (`grep NEKO_PASSWORD docker/.env`). Войдите на свои сайты там, один раз.

**Библиотека** — из вашего проекта. В npm её нет: ставьте из клона (`npm install ../meatsuit`, в `package.json` запишется зависимость `file:`). Порт CDP доступен только в сети зеркала: запускайте код в контейнере с `network_mode: "container:meatsuit-browser"` (чтобы просто попробовать — локальный Chromium с `--remote-debugging-port=9222`):

```js
const { connect } = require('meatsuit');   // CommonJS: строки ниже — внутри async-функции

const ms = await connect({
  cdpUrl: 'http://127.0.0.1:9222',
  sitesFile: './sites.json',      // ваши лимиты площадок; начните с sites.example.json
  dir: '/meatsuit/state',         // замок очереди и счётчики: один dir на всех вызывающих (state/ в томе meatsuit_profile)
  notify: async (text) => { /* ваш Telegram, почта…: токен остаётся у вас */ },
});
const title = await ms.task('read-title', async ({ see, act }) => {
  await act({ cmd: 'goto', url: 'https://example.com/' });
  return (await see()).title;
}, { site: 'example.com', dryRun: true });   // первый запуск на живой площадке — только dryRun
await ms.close();
```

`goto` принимает только `https` на хосте `site` задачи. Лимиты из `sites.example.json` пускают `example.com` только с 10 до 23 часов по поясу процесса (остальные площадки — с 9 до 21): в другое время задача бросает `LimitReached`, не трогая браузер. `peek(site, { sitesFile, dir })` показывает остаток лимитов площадки, не тратя слот. Весь интерфейс — снимки `see()`, закрытый набор команд, `sites.json`, ошибки, журнал и запись — в [docs/04-contract.md](docs/04-contract.md).

## Настройки

У meatsuit два вида настроек, и они не смешиваются.

**Файл деплоя** — только то, что принадлежит серверу зеркала: пароли зеркала, адрес и порты, браузер и тег его образа, папка профиля, часовой пояс, потолки процессора и памяти, выход через Tailscale по желанию. Это `docker/.env` или файл, на который указывает `MEATSUIT_CONFIG` (может лежать вне репозитория). Все переменные с умолчаниями — в таблице [docker/README.md](docker/README.md#the-deploy-file-and-dockerupsh) (по-английски; кратко по-русски — [docker/README.ru.md](docker/README.ru.md)), образец с комментариями — [`docker/.env.example`](docker/.env.example).

- `npm run init` создаёт его из образца: права 0600, случайные hex-пароли. Если файл есть, ничего не меняет (только перечислит, что не так).
- `npm run config` — временный процесс на хосте, не в контейнере и не в сети браузера: страница на `127.0.0.1`, одноразовый токен в ссылке, без cookies, проверка `Origin`, пароли на страницу не отдаются, запись атомарная с правами 0600, `409`, если файл успели поменять, выход после 15 минут простоя. `npm run config -- --tailnet` — на адресе tailnet сервера.
- `docker/up.sh` передаёт файл в `docker compose --env-file`. Compose читает его только при `up`: после правки снова `docker/up.sh`.

**Настройки вызывающего** — аргументы, а не файлы meatsuit: `connect({ cdpUrl, sitesFile, dir, notify })` и `task(name, fn, { site, uploadDirs, dryRun, … })`. Библиотека не читает окружение. Файл лимитов `sites.json` у каждого вызывающего свой ([04-contract.md](docs/04-contract.md#connect-и-task)).

**Браузер.** `MEATSUIT_BROWSER=chrome` (по умолчанию) или `brave`. У каждого браузера свой том профиля — `meatsuit_profile` у Chrome, `meatsuit_brave_profile` у Brave, — поэтому после смены входить на сайты заново. Контейнер всегда называется `meatsuit-browser`: другие стеки подключаются к нему через `network_mode: "container:meatsuit-browser"` и видят CDP на `http://127.0.0.1:9222`. На хосте CDP не публикуется никогда. Вызывающие подключают том `meatsuit_profile` (external) и держат общий `dir` в его папке `state/`.

**Выход.** По желанию трафик браузера уходит через exit node Tailscale дома (`MEATSUIT_EGRESS=tailscale`) с выключателем: нет туннеля — нет сети. Список exit node с запасным и проверкой страны и провайдера — `MEATSUIT_EXIT_NODES` ([docs/egress.md](docs/egress.md)).

## Деплой

На сервере: Docker с Compose 2.24+, Tailscale на хосте, зеркало привязано к адресу tailnet сервера, никогда к `0.0.0.0`. Шаги — [docker/README.ru.md](docker/README.ru.md#развёртывание-на-сервере), потом живая проверка [docs/acceptance.md](docs/acceptance.md) и, по желанию, выход через дом ([docs/egress.md](docs/egress.md#recommended-setup)). Стек запускать всегда через `docker/up.sh`: голый `docker compose up` про Tailscale не знает.

Сервер владельца работает на версии `ms-trunk` (см. «Состояние»). Перевод на `main` и на список exit node — [docs/ru/09-phone-exit-node.md](docs/ru/09-phone-exit-node.md).

## Что где лежит

| Путь | Что это |
|---|---|
| `index.js` | `connect()` и `task()`: очередь, лимиты, бюджет, окно на задачу, присмотр, `peek()` |
| `eyes.js`, `dom.js` | `see()`: страница текстом и элементами с номерами, разница между снимками |
| `hands.js`, `human.js`, `human/` | `act()`: закрытый набор команд, мышь, колесо и клавиатура в темпе человека |
| `guard.js`, `supervise.js` | капча, вход и блок превращаются в `NeedsHuman`; путь входа по коду по желанию |
| `limits.js`, `window.js`, `capture.js` | лимиты из `sites.json` вызывающего, окна задач, архив экранов по желанию |
| `telegram.js` | помощник для `notify`: токен и чат передаёт вызывающий, из окружения ничего не читается |
| `sites.example.json` | образец файла лимитов; настоящий у каждого вызывающего свой |
| `config.js`, `tools/` | файл деплоя (`init.js`, `config-ui.js`), `live-check.js` для приёмки, `secret-scan.sh` и его хук, `save-tab.js`, `telegram-chats.js` |
| `docker/` | зеркало: Neko с Chrome или Brave, `up.sh`, `verify.sh`, выход через Tailscale по желанию (`egress/killswitch.sh`, `egress/exit-picker.sh`) |
| `extras/` | поддерживаемые сервисы вокруг ядра со своими копиями рук и лимитов: HTTP-сервис, прогрев, проверка выхода, очередь, уведомления, хозяин у руля, замок браузера и `selfcheck.js` ([docs/README.md](docs/README.md#extras-services-around-the-core)). Ядро из `extras/` ничего не берёт (проверяет `test/api.test.js`) |
| `profiles/` | образцы для сервисов `extras/` (`*.example.json`); настоящие файлы вне git |
| `test/` | тесты ядра, файла деплоя, скана секретов, файлов Docker и `exit-picker.sh` |

## Неполадки

Симптомы зеркала (нет файла деплоя, не становится healthy, нет видео, выкинуло из аккаунтов после перезапуска, «профиль используется», с Tailscale ничего не стартует, ворота выхода закрыты) — в [docker/README.ru.md](docker/README.ru.md#неполадки). Библиотека: `connect` падает, не трогая браузер, если `sitesFile` нет или заданы и `sitesFile`, и `sites`; задача, остановленная `NeedsHuman`, оставляет окно вам в зеркале; ошибки и их поля — в [04-contract.md](docs/04-contract.md#ошибки).
