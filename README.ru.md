# meatsuit

**Один прогретый браузер на сервере. Вы живёте в нём, а ваши скрипты работают в нём человеческими руками.**

[English](README.md) · [Документация](docs/README.md) · [Как участвовать](CONTRIBUTING.md)

meatsuit запускает один постоянный настоящий Brave в Docker. Вы открываете его через веб-зеркало (картинка и звук по WebRTC) и пользуетесь как обычным браузером: входите на сайты, смотрите, читаете. Ваша автоматизация подключается к **тому же** браузеру через небольшой HTTP-сервис и действует человеческими мышью, клавиатурой и прокруткой: медленно, по одной задаче, в заданных вами лимитах, а на капче останавливается, а не пытается её обойти.

```
  вы (телефон, ноутбук)            ваши скрипты (на любом языке)
          │ веб-зеркало                     │ GET /view, POST /act
          ▼                                 ▼
 ┌─────────────────────── сервер (Docker) ────────────────────────┐
 │  Neko + Brave, постоянный профиль ◄── CDP ── HTTP-сервис       │
 │                                           очередь · лимиты · guard │
 │                                           человеческие руки    │
 └──────────────────────────────┬─────────────────────────────────┘
                                │ весь трафик браузера выходит через ваш домашний узел
                                ▼
                  ваше домашнее подключение (ваш настоящий IP)
```

## Зачем

Одноразовые автоматические браузеры, адреса датацентров и механический ввод выглядят иначе, чем человек в своём браузере. Ставка meatsuit: не прятать автоматизацию за подменой, а сделать так, чтобы она выглядела тем, чем и является: настоящий браузер одного человека, из его сети, понемногу.

Это гипотеза, а не гарантия. Что именно смотрят сайты, никто не публикует, и проект не обещает, что автоматизация незаметна. Что проверено и что нет, смотрите в [Состоянии](#состояние).

## Что есть

- **Зеркало браузера** ([Neko](https://github.com/m1k1o/neko) с Brave в Docker). Профиль сохраняется: вошли один раз и остались вошедшими.
- **HTTP-интерфейс** для скриптов: `GET /view` отдаёт простой HTML того, что видно, с номерами у интерактивных элементов; `POST /act` делает одно действие (клик, ввод, прокрутка, переход) по номеру, по видимому тексту или по CSS.
- **Человеческие руки.** Мышь идёт слегка по кривой со временем по закону Фиттса, дрожью, иногда подёргиванием и перелётом. Печать клавиша за клавишей с живым ритмом, опечатками на соседних клавишах и исправлением, настоящие раскладки латиница и кириллица. Колесо рывками с паузами «прочитать».
- **Ограждения.** Одна задача за раз. Лимиты площадок ведут себя как человек (постепенный рост, выходные, разброс по дням, пауза на несколько суток после проверки). Капча, блок и страница входа распознаются, задача останавливается, человек решает её в зеркале. Проверка выхода не даёт работать, если трафик идёт не из ожидаемой страны и сети.
- **Необязательный прогрев.** Планировщик, который несколько дней в неделю читает обычные сайты как человек (листает, идёт по ссылке, закрывает баннер cookies, ищет на Википедии). Только читает, никогда не входит и не пишет.

## Чего здесь нет

- Это не ферма аккаунтов и не для чужих аккаунтов. Только **ваши** аккаунты и понемногу.
- Это не решатель капчи. На капче останавливается и спрашивает вас.
- Это не подмена отпечатков. Браузер настоящий и не притворяется другим.
- Это не обещание безопасности. У сайтов свои правила: условия Tinder и справка LinkedIn (проверено) запрещают автоматизацию, числовых лимитов не публикуют ни те, ни другие. **Вы отвечаете за то, что автоматизируете, и за условия, с которыми согласились.**

## Состояние

| | |
|---|---|
| **Построено и проверено** (тесты и настоящий Chromium; зеркало в Docker на машине автора) | руки, чтение страницы и действия, HTTP-сервис с очередью, лимитами и токенами, распознавание капчи и блока, планировщик и сессии прогрева, зеркало (открывается, показывает живой Brave, держит профиль между перезапусками, прокручивается из зеркала) |
| **Построено, проверено частично** (один запуск на арендованном сервере) | зеркало на настоящем сервере: поднялось, и видео шло по tailnet, проверено из headless Chromium на ноутбуке. Там работало только зеркало: без выхода через дом, HTTP-сервиса и прогрева ([подробности](docker/README.md#what-was-verified-and-what-was-not)) |
| **Построено, не проверено** | выход через Tailscale и правило «нет туннеля — нет сети» (конфигурация валидна, не запускалась; тестовый контейнер на том сервере принял TUN и нужные возможности `iptables`); HTTP-сервис контейнером Docker (compose его принимает, не запускался); звук; видео в настоящем браузере или на телефоне по tailnet; Enter из веб-клиента настоящей клавиатурой |
| **Не проверено совсем** | Brave на реальных сайтах; сайты-детекторы; прогрев в течение недель; как отреагирует конкретный сайт |
| **Догадки автора** | все числа в лимитах и прогреве по умолчанию (срок роста, выходные, разброс, пауза после проверки) стартовые, не измеренные |

Около 400 тестов (`npm test`); те, которым нужен браузер, сами пропускаются, когда его нет.

## Быстрый старт

Нужны: Node 20+, Docker для зеркала.

```sh
npm install
npm test                     # браузерные тесты пропускаются без Patchright и Chromium

npm run init                 # docker/.env: случайные пароли зеркала, права 0600; повторно ничего не трогает
npm run config               # по желанию: страница на 127.0.0.1, чтобы посмотреть и поправить (печатает одноразовую ссылку)
cd docker
docker compose up -d
./verify.sh                  # открывает страницу из зеркала, прокручивает, проверяет по CDP
# затем http://127.0.0.1:8080 (имя любое, пароль из .env)

cd ..
cp profiles/life.example.json profiles/life.json   # своя копия, в git не попадает
node life.js plan            # что сделал бы прогрев (браузер не нужен)
node life.js now --dry
```

Пример работы HTTP-сервиса с `curl` и описание всех действий — в [docs/http-api.md](docs/http-api.md). С зеркалом в Docker сервис запускается контейнером рядом с браузером: `docker compose --profile api up -d` (см. [docker/README.md](docker/README.md#http-service); в контейнере пока не проверялся). Не выставляйте сервис и зеркало в открытый интернет: слушайте только localhost или закрытую сеть вроде адреса Tailscale.

## Устройство кода

| Путь | Что это |
|---|---|
| `human.js`, `human/` | мышь, клавиатура и прокрутка с человеческим темпом |
| `view.js`, `driver.js` | копия видимого HTML и драйвер браузера (Patchright по CDP) |
| `server.js`, `queue.js`, `limits.js`, `egress.js`, `notify.js` | HTTP-сервис: токены, очередь по одному, лимиты, проверка выхода, уведомления в Telegram |
| `guard.js` | распознаёт капчу, блок и страницу входа |
| `life.js`, `life/` | планировщик и сессии прогрева |
| `docker/` | зеркало: Neko и Brave, необязательные сервисы прогрева, HTTP-интерфейса и выхода через дом |
| `profiles/` | примеры конфигурации |
| `test/`, `testkit/` | тесты и фальшивая страница для юнит-тестов |
| `scripts/capped` | запуск команды с жёстким потолком памяти и процессора |
