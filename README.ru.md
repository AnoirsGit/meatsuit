# meatsuit

**meatsuit — это просто запуск браузера, запоминание и потом глаза и руки. Все учётные данные (креденшелы) выдаёт тот, кто обращается.**

[English](README.md) · [Документация](docs/README.md) · [Что дальше](docs/ROADMAP.md) · [Как участвовать](CONTRIBUTING.md)

Больше ничего. meatsuit запускает один браузер, хранит его профиль, чтобы вход, сделанный один раз, не пропадал, и даёт вашему коду смотреть на страницу (глаза) и действовать в ней как человек (руки). Своих аккаунтов, задач и расписания у него нет: пароли, токены, лимиты и решение, что делать, приносит вызывающий. На деле это две части:

1. **Библиотека для Node** (`connect` / `task` / `see` / `act`). Ваш проект подключается к запущенному браузеру по CDP, берёт его на одну короткую задачу за раз, видит страницу как текст и список элементов с номерами и действует по ним человеческими мышью и клавиатурой. Капча, страница входа или блок останавливают задачу (`NeedsHuman`), окно остаётся человеку.
2. **Зеркало браузера** в Docker ([Neko](https://github.com/m1k1o/neko)): один постоянный браузер — по умолчанию Google Chrome, можно Brave, — который человек открывает с обычной веб-страницы. Профиль живёт в томе: вход на сайты делается руками один раз, и этой сессией пользуются все вызывающие.

Учётные данные всегда приносит вызывающий. Библиотека не читает окружение и сама никуда не шлёт: лимиты площадок (`sitesFile`), каталог состояния (`dir`) и уведомления (`notify`) — аргументы `connect()`. Паролей сайтов, ключей моделей и токенов ботов в meatsuit нет.

```
  ваш проект (Node)                            вы (ноутбук, телефон)
  connect({ cdpUrl, sitesFile, notify })               │ веб-зеркало (WebRTC)
  task(site, ({ see, act }) => …)                      ▼
          │ CDP                      ┌──── Docker: контейнер meatsuit-browser ────┐
          └────────────────────────► │ Neko + Google Chrome (или Brave), CDP 9222  │
                                     │ профиль в томе meatsuit_profile             │
                                     └─────────────────────────────────────────────┘
```

## Быстрый старт

Нужны Node 20+, для зеркала — Docker с Compose 2.24 или новее.

**Зеркало.**

```sh
npm ci
npm run init        # файл деплоя docker/.env: права 0600, случайные пароли зеркала; повторно ничего не трогает
npm run config      # по желанию: временная страница на 127.0.0.1, чтобы посмотреть и поправить файл (печатает одноразовую ссылку)
docker/up.sh        # docker compose --env-file <файл деплоя> up -d
docker/verify.sh    # управляет зеркалом и проверяет по CDP, что браузер действительно это сделал
```

Откройте `http://127.0.0.1:8080`, имя любое, пароль участника — из файла деплоя (`grep NEKO_PASSWORD docker/.env`). Войдите на свои сайты там, один раз.

**Библиотека** — из вашего проекта. Порт CDP доступен только в сети зеркала: запускайте код в контейнере с `network_mode: "container:meatsuit-browser"` (чтобы просто попробовать — локальный Chromium с `--remote-debugging-port=9222`):

```js
const { connect } = require('meatsuit');

const ms = await connect({
  cdpUrl: 'http://127.0.0.1:9222',
  sitesFile: './sites.json',      // ваши лимиты площадок; начните с sites.example.json
  dir: '/meatsuit/state',         // замок очереди и счётчики: один dir на всех вызывающих (state/ в томе meatsuit_profile)
  notify: async (text) => { /* ваш Telegram, почта…: токен остаётся у вас */ },
});
const title = await ms.task('read-title', async ({ see, act }) => {
  await act({ cmd: 'goto', url: 'https://example.com/' });
  return (await see()).title;
}, { site: 'example.com', dryRun: true });   // первый запуск на живой площадке — только dryRun
await ms.close();
```

`peek(site, { sitesFile, dir })` показывает остаток лимитов площадки, не тратя слот. Весь интерфейс — снимки `see()`, закрытый набор команд, `sites.json`, ошибки, журнал и запись — в [docs/04-contract.md](docs/04-contract.md).

## Файл деплоя

Один файл вне git, и в нём только то, что принадлежит серверу зеркала: пароли зеркала, адрес и порты, браузер и тег его образа, папка профиля, часовой пояс, потолки процессора и памяти. Это `docker/.env` или файл, на который указывает `MEATSUIT_CONFIG` (может лежать вне репозитория).

- `npm run init` создаёт его из [`docker/.env.example`](docker/.env.example): права 0600, случайные hex-пароли. Если файл есть, ничего не меняет.
- `npm run config` — временный процесс на хосте, не в контейнере и не в сети браузера: страница на `127.0.0.1`, одноразовый токен в ссылке, без cookies, проверка `Origin`, пароли на страницу не отдаются, запись атомарная с правами 0600, `409`, если файл успели поменять, выход после 15 минут простоя.
- `docker/up.sh` передаёт файл в `docker compose --env-file`. Compose читает его только при `up`: после правки снова `docker/up.sh`.

Настроек вызывающих в этом файле нет: лимиты, папки для загрузки и каталог состояния — аргументы `connect()` и `task()`.

## Выбор браузера

`MEATSUIT_BROWSER=chrome` (по умолчанию) или `brave` в файле деплоя. У каждого браузера свой том профиля — `meatsuit_profile` у Chrome, `meatsuit_brave_profile` у Brave, — поэтому после смены входить на сайты заново. Контейнер всегда называется `meatsuit-browser`: другие стеки подключаются к нему через `network_mode: "container:meatsuit-browser"` и видят CDP на `http://127.0.0.1:9222`. На хосте CDP не публикуется никогда. Вызывающие подключают том `meatsuit_profile` (external) и держат общий `dir` в его папке `state/`. Подробно: [docker/README.ru.md](docker/README.ru.md).

По желанию: выпускать трафик браузера через exit node Tailscale (`MEATSUIT_EGRESS=tailscale`, см. [docs/egress.md](docs/egress.md)).

## Что где лежит

| Путь | Что это |
|---|---|
| `index.js` | `connect()` и `task()`: очередь, лимиты, бюджет, окно на задачу, присмотр |
| `eyes.js`, `dom.js` | `see()`: страница текстом и элементами с номерами, разница между снимками |
| `hands.js`, `human.js` | `act()`: закрытый набор команд, мышь и клавиатура в темпе человека |
| `guard.js`, `supervise.js` | капча, вход и блок превращаются в `NeedsHuman` |
| `limits.js`, `window.js`, `capture.js` | лимиты из `sites.json` вызывающего, окна задач, архив экранов по желанию |
| `telegram.js` | помощник для `notify`: токен и чат передаёт вызывающий, из окружения ничего не читается |
| `sites.example.json` | образец файла лимитов; настоящий у каждого вызывающего свой |
| `config.js`, `tools/` | файл деплоя (`npm run init`, `npm run config`), скан секретов, мелкие программы для человека |
| `docker/` | зеркало: Neko с Chrome или Brave, `up.sh`, `verify.sh`, выход через Tailscale по желанию |
| `extras/` | **заморожено**: HTTP-сервис, прогрев, проверка выхода и их собственные копии рук и лимитов от прежней линии работ. Работают и тестируются (`npm run test:extras`), но не развиваются, нового туда не добавляют; ядро из них ничего не берёт |
| `test/` | тесты ядра, файла деплоя, скана секретов и файлов Docker |

## Состояние

На 8 октября 2026.

| | |
|---|---|
| **Работает на сервере** | этот compose с Google Chrome, профиль в томе `meatsuit_profile`, трафик выходит через домашний exit node Tailscale (профиль `egress`); `docker/verify.sh` зелёный; cookie и `localStorage` переживают перезапуск и пересоздание контейнера (`verify.sh persistence`). Один проект-вызывающий подключён через `container:meatsuit-browser`, вход сделан руками один раз и держится; запускались только `dryRun`-задачи |
| **Проверено тестами** | библиотека в настоящем Chromium на локальных страницах (`npm test`); файл деплоя, `npm run init`, `npm run config`, скан секретов; `docker compose config` для обоих браузеров, с Tailscale и без |
| **Ещё не запускалось** | этот compose с Brave; выключатель при выключенном exit node (правда ли браузер остаётся без сети, а не выходит с адреса сервера); Enter и сочетания с настоящей клавиатуры; записанная строка [приёмки](docs/acceptance.md) на сервере |

В истории git ещё есть личные данные прежней работы, её перепишут; `main` на GitHub старее рабочей ветки. Открытые пункты по приоритету: [docs/ROADMAP.md](docs/ROADMAP.md).

meatsuit — для автоматизации **своих** аккаунтов понемногу. Он не решает капчу, не подменяет отпечатки и ничего не обещает про реакцию сайтов. Правила площадок действуют, отвечаете за них вы.
