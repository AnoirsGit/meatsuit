# meatsuit

Один прогретый браузер на сервере: я в нём живу (зеркало через Neko), мои боты из других проектов в нём работают человеческими руками.

- [Цель](docs/02-goal.md)
- [Что уже есть у нас и у других](docs/01-analysis.md)
- [Как устроено и как пользоваться](docs/03-design.md)

Код: `human.js` (руки: мышь, прокрутка, ввод), `eyes.js` (снимок страницы для модели), `hands.js` (закрытый набор команд по номерам из снимка, `dryRun`, журнал, запись и воспроизведение), `guard.js` (капча, вход, блокировка → стоп и телега), `limits.js` (лимиты, часы, очередь), `index.js` (`connect()` и `task()`), `telegram.js` (бот в группу: отправка, повторы, поиск chat_id). Лимиты площадок в `sites.json`. Тесты: `npm test`.

**Ручное сохранение экранов** (для настройки правил по живой площадке): `tools/save-tab.js`.
- Подключение к вашему браузеру: `node tools/save-tab.js --cdp http://127.0.0.1:9222 --filter tinder.com --dir ./archive-manual --watch`. Листаете руками, инструмент сохраняет каждый новый тип экрана (снимок плюс очищенный HTML). Подключение по CDP включает у страниц режим отладки, сайт теоретически может это заметить, поэтому на живом аккаунте брать на короткое время.
- Без подключения, нулевой риск: сохраните страницу сами («Сохранить как» → «Только HTML») и выполните `node tools/save-tab.js --sanitize страница.html --dir ./archive-manual`. Очищенная копия ляжет в `archive-manual/sanitized/`.
- Очистка: тела `script`/`style`, `value` у полей ввода (пароль, почта, телефон, csrf), `content` у `meta` с токенами, длинные `data:`-URI. В архиве всё равно настоящие страницы с чужими именами и фото: хранить локально и не коммитить.
